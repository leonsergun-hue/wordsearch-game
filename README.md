# Word Search Game

Простая игра «Найди слова» на чистом HTML/CSS/JavaScript.

## Запуск

1. Скачайте/клонируйте репозиторий.
2. Откройте файл `index.html` в браузере.

## Управление

- Зажмите кнопку мыши на букве и тяните по прямой (включая диагонали), затем отпустите.
- Если получилось слово из списка — оно засчитается как найденное.
- Кнопка **Новая игра** генерирует новую сетку.
- Кнопка **Подсказка** подсвечивает первое не найденное слово на 1 секунду.
- Кнопка **Сброс** очищает прогресс найденных слов в текущей сетке.
